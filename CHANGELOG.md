# Changelog

## 1.0.0 (2026-10-29)
- First public release.
- Shows the hidden Create Room / Join By Code menu.
- Internet co-op through Steam lobbies and Steam P2P relay (no port forwarding).
- Optional direct IP join (`ExtraHosts` in the config).
- Room search and join timeouts raised from 8 s to 20 s for internet latency.
- Protocol version check: a clear message when host and client have different VoxelCoop versions.
- Russian / English status text (auto by system language).
